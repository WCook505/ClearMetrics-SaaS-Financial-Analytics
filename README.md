ClearMetrics | SaaS Financial Analytics

Project Overview 📁

ClearMetrics is a fictional B2B SaaS company offering subscription-based software services to customers across different industries and geographic regions.

This project simulates the responsibilities of a Financial Data Analyst tasked with evaluating billing performance, identifying trends, and delivering actionable business insights.

Using MySQL and Power BI, I developed a relational star schema, analyzed financial transactions using SQL, and created an interactive dashboard to communicate key performance indicators.

Business Objectives 🎯

Evaluate monthly invoiced revenue trends and growth.

Identify the highest-contributing subscription plans.

Analyze customer performance by industry and region.

Identify the top 10 customers by invoiced revenue.

Develop an interactive dashboard for financial reporting.

Tools and Technologies 🔧

MySQL Workbench: Database development, SQL querying, and data modeling.

SQL: Joins, CTEs, aggregations, and window functions.

Power BI: Data modeling, DAX measures, and interactive visualization.

GitHub: Project documentation and version control.

Dataset 📊

The project uses synthetic SaaS financial data consisting of customers, subscription plans, subscriptions, invoices, and payments.

The data is fictional and intended for demonstrating financial analytics techniques.
