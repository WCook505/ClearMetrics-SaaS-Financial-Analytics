Database Development

The original database contains five tables:

Customers: Customer information, industries, and regions.

Plans: Available subscription plans and pricing.

Subscriptions: Customer subscriptions and billing cycles.

Invoices: Billing transactions, dates, amounts, and statuses.

Payments: Customer payment transactions.

I also developed a star schema to make the data easier to analyze in Power BI.

The star schema includes one invoice fact table and three dimension tables for customers, plans, and dates.

SQL Analysis

SQL was used to explore financial performance and answer questions such as:

How is invoiced revenue changing each month?

Which subscription plans generate the most revenue?

Which industries and regions contribute the most?

Who are the company's highest-value customers?
